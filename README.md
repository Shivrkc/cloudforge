# CloudForge

> **From Code to Cloud.**

CloudForge is a modern cloud deployment platform built for developers who want a simple and reliable way to deploy applications.

Inspired by platforms like **Vercel**, **Railway**, **Render**, and **Coolify**, CloudForge aims to make deploying projects as simple as pushing code to GitHub.

---

## About

CloudForge is a personal portfolio project focused on building a production-style deployment platform while following modern software engineering practices.

Instead of being a simple frontend clone, the goal is to gradually evolve it into a complete deployment platform with authentication, project management, CI/CD, Docker, cloud infrastructure, and monitoring.

## Why CloudForge?

This project is being built to explore the engineering behind modern deployment platforms.

The focus isn't only on writing code, but on designing scalable architecture, reusable components, clean UI, and production-ready workflows.

Every feature is implemented incrementally with long-term maintainability in mind.

## Getting Started

Clone the repository

```bash

git clone [https://github.com/Shivrkc/cloudforge.git](https://github.com/Shivrkc/cloudforge.git)

```

Install dependencies

```bash

npm install

```

Start the development server

```bash

npm run dev

```
